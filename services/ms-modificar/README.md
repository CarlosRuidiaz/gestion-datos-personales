# ms-modificar

Microservicio NestJS de la opción **Modificar Datos Personales**. Ruta en el gateway: `/api/modificar`. Usuario de base de datos: `usr_modificar`.

Aquí irá: `GET` y `PUT /api/modificar/personas/{documento}`: búsqueda previa propia (se registra como CONSULTAR) y actualización con log en la misma transacción.

Tarea del tablero que llena esta carpeta: **T07**. Ver `CONTEXTO.md` y las secciones 5.3 y 8.1 de `docs/diseno/documento_diseno.md`.
