# ms-crear

Microservicio NestJS de la opción **Crear Personas**. Ruta en el gateway: `/api/crear`. Usuario de base de datos: `usr_crear`.

Aquí irá: `POST /api/crear/personas`, con validaciones, verificación de documento duplicado y log en la misma transacción.

Tarea del tablero que llena esta carpeta: **T06**. Ver `CONTEXTO.md` y las secciones 5.3 y 8.1 de `docs/diseno/documento_diseno.md`.
