# ms-log

Microservicio NestJS de la opción **Consultar log**. Ruta en el gateway: `/api/log`. Usuario de base de datos: `usr_log`.

Aquí irá: `GET /api/log?tipo=&documento=&desde=&hasta=` y `POST /api/log/consulta-nl` (protegido con la llave de API de n8n).

Tarea del tablero que llena esta carpeta: **T10**. Ver `CONTEXTO.md` y las secciones 5.3 y 8.1 de `docs/diseno/documento_diseno.md`.
