# ms-borrar

Microservicio NestJS de la opción **Borrar Personas**. Ruta en el gateway: `/api/borrar`. Usuario de base de datos: `usr_borrar`.

Aquí irá: `GET` y `DELETE /api/borrar/personas/{documento}`: búsqueda previa propia (se registra como CONSULTAR) y borrado con log en la misma transacción.

Tarea del tablero que llena esta carpeta: **T09**. Ver `CONTEXTO.md` y las secciones 5.3 y 8.1 de `docs/diseno/documento_diseno.md`.
